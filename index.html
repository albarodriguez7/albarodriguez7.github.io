Proceso

Cómo trabajo

1. Caso de uso
Entender la necesidad del negocio y qué tiene que resolver el asistente o el agente.
2. Diseño del agente
Elegir herramientas, fuentes de información (RAG), memoria y cómo se conecta con APIs y bases de datos.
3. Prueba y evaluación
Tests automatizados y trazas con LangSmith para revisar la calidad y la consistencia de las respuestas.
4. Interfaz y despliegue
Interfaces en Streamlit y APIs con FastAPI, desplegadas en la nube.
5. Documentación
README y notas con las decisiones técnicas, para que el proyecto se pueda entender y seguir mejorando.
